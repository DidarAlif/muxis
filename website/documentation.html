Muxis Documentation

1. Architecture & Data Boundary

Muxis enforces a strict boundary between Local Audio Files and Cloud Metadata:

  • Local Files Never Uploaded: Your FLAC, MP3, WAV, and audio files reside exclusively on your local storage device. No local audio is transmitted to cloud servers.
  • Portable Cloud References: Cloud playlists store canonical track metadata (ISRC, title, artist, album, duration) rather than absolute file paths, allowing playlists to sync across different devices without path collisions.
  • Offline-First Resilience: All playback, library scanning, equalizer, and queue controls operate completely offline. When internet is restored, changes sync asynchronously via Supabase PostgreSQL.

2. Audio Studio & DSP Engine

Muxis features a built-in digital signal processing suite:

  • 5-Band Master Equalizer: 60Hz (sub-bass), 230Hz (bass), 910Hz (midrange), 3.6kHz (upper mids), and 14kHz (high treble) with ±12dB parametric curve.
  • Karaoke Vocal Isolation: Employs center-channel phase cancellation (Left - Right) to attenuate center-panned lead vocals while preserving ambient instrumentation.
  • Pitch & Tempo Stretching: Real-time pitch shifting and playback speed modulation (0.5x to 2.0x) with a single-tap Slowed + Reverb preset.
