User Guide & Architecture

MUXIS Documentation

Complete reference for whole-storage indexing, 10-band Audio Studio DSP, MUXIS Cloud synchronization, and keyboard ergonomics.

1. Importing Local Music & Full-Storage Scan

Click Import Music in the Library view to select individual folders or run a full-device storage sweep across supported formats (.mp3, .flac, .wav, .aac, .m4a, .ogg, .opus).

Android: Grant media audio storage access when prompted so MUXIS recursively indexes internal memory and mounted SD card music directories automatically.

iPhone / iPad: Copy offline audio folders into Files → On My iPhone → MUXIS → Music or pick any shared cloud/local iOS directory via the native document picker.

2. Audio Studio & 10-Band Parametric DSP

Open Audio Studio from the sidebar or player dock to sculpt frequency gain across 10 bands (32Hz, 64Hz, 125Hz, 250Hz, 500Hz, 1k, 2k, 4k, 8k, 16kHz).

Select instant Studio Presets (Prismatic Neon, Sub Bass Thump, Vocal Clarity, Electronic & EDM, Rock & Metal, Jazz & Acoustic, Lo-Fi Warmth, or Flat), balance Sub-Bass Drive, Treble Air, and Pre-Amp Gain, or toggle Master Bypass for A/B comparison.

3. MUXIS Cloud (Firebase Auth + Cloudflare D1 Sync)

Open Cloud Sign In in the bottom left (or Settings) to authenticate with 1-Click Google Sign-In powered by Firebase Authentication or create an email/password account.

Your playlists, favorite tracks, listening history, 10-band EQ profile, and custom theme preferences synchronize across Desktop, Android, and iPhone through encrypted Cloudflare Workers & Cloudflare D1 edge storage. Audio files themselves never leave your device.

4. Synchronized Lyrics & Stream Bridges

Place matching .lrc files beside local tracks or stream connected YouTube Music, Spotify Hi-Fi Bridge, SoundCloud, and live FM Radio channels straight inside one unified player queue.
