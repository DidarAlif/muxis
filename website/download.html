Installing MUXIS on iPhone / iPad (.ipa) & Android Updates

iPhone / iPad: Install Muxis-iOS.ipa onto your device using AltStore, SideStore, or Sideloadly with your Apple ID. Place offline music folders into the iOS Files app under On My iPhone → MUXIS → Music (or scan shared folders) and tap Scan Storage inside the app.

Android: Starting from v1.2.13, all GitHub release APKs use a permanent RSA-2048 signing certificate so future updates install smoothly in place. If you still have an older build from v1.2.12 or earlier, uninstall it once before installing v1.2.13+ (your MUXIS Cloud playlists, favorites & themes restore immediately upon sign-in).
